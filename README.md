Gertion de Clinica Veterinaria

Instrucciones:
1. Clonar a Repo a visual
2. Abrir Compass
3. Crear la coneccion local por defecto en puerto 27017 (sino se ha realizado)
4. En consola visual verificar que pymogo este instalado en visual: pip install pimongo
5. Generar la base de datos local en compas del archivo seed.py: python seed.py
6. (opcional) actualizar la coneccion en compass y verificar la creacion de la base de datos local
7. Ejecutar archivo main.py: python main.py
